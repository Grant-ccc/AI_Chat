# 自动转人工与交接摘要

2026-10-10：普通商品问答仍使用完整公开prompt和本轮对话生成自然回复。仅调整转人工动作说明，无检索、训练或候选审核队列。

明确的整句人工请求直接进入人工队列；混合问题、换货退款申请等由模型选择一个transfer_to_human动作，后台校验后在同一事务保存回复和交接。动作中的reply应包含可回答的商品事实，转交成功确认由后台发送。按钮继续可用。等待人工和人工接待期间暂停AI。

交接成功后独立整理商家摘要，包含用户诉求、已知情况、已尝试操作、材料情况。无信息显示未提供。摘要每条附用户原话和消息序号，后台校验引用确实来自本轮真实用户消息；这不能保证模型概括语义完全正确，商家仍须核对。用户接口不返回摘要，摘要也不写进公开聊天。

摘要只覆盖上一轮人工结束后至本次转交时的消息，转交后的补充保留在聊天中并提示商家查看。旧交接摘要迟到不能覆盖新交接。摘要生成或额度失败均不阻止接手；重启后未完成任务标记失败，不自动重试。无历史或仅明确人工请求时可直接整理，不额外调用模型。

真实模式通常在自动转交时使用一次回答调用、一次摘要调用；与普通回答共用原有调用数和金额上限。mock用于流程验收，不代表真实模型识别率。只支持文字材料说明，不接收或审核附件。

验收：独立MySQL测试库的后端测试、前端构建及Edge模拟网页流程；测试覆盖引用校验、用户隔离、重复交接、摘要失败可接手、补充范围和新轮次隔离。

本次结果：38项后端检查通过，前端构建通过，三组Edge流程验收通过。真实模型一次混合问价与换货请求正确返回转交动作；一次摘要的诉求、瑕疵情况、缺订单截图均附真实原文，已尝试操作为空。两次均计入既有账本，未提高上限。
