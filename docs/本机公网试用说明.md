# 本机公网试用

通过花生壳HTTPS映射将公网入口转发至本机127.0.0.1:5173。穿透节点必须安装在运行项目的同一台电脑上，并保持在线。

## 启动

先在frontend目录执行`npm run build`，再在项目根目录执行：

```powershell
powershell -File scripts/stop-dev.ps1
.venv\Scripts\python.exe -X utf8 scripts/start_dev.py --public-origin https://你的穿透域名
```

脚本仅允许明确的HTTPS来源，网页只允许该来源的域名，API校验Origin并启用Secure Cookie。网页使用Vite preview提供构建产物，通过同源/api代理访问本机后端。这是短期朋友试用方式，Vite preview不是正式生产服务器；正式部署另行配置。

用户访问HTTPS入口，商家访问相同入口的/merchant。公网试用模式下，电脑端也使用该HTTPS入口操作，localhost页面的提交请求会被来源校验拒绝。两种网址的浏览器Cookie不同，历史访客会话不会自动迁移。

关闭电脑、休眠、断网或停止穿透节点都会中断访问。数据库与API仍仅监听本机，不另行映射数据库、远程桌面或管理端口。域名变化后须使用新--public-origin重启；修改前端后须重新构建。

## 验证与排查

- Service Unavailable：检查节点在线状态和本机5173可达性。
- Blocked request / host is not allowed：确认启动时传入正确的完整HTTPS来源，不能把allowedHosts设为true。
- 请求来源不允许：确认通过配置的同一HTTPS网址访问，不混用localhost或旧域名。
- 当前验证：公网用户页、商家页、health接口返回200；访客会话创建与读取通过；Cookie含Secure；未知Host和Origin均返回403。未因连接验证产生模型调用。

穿透令牌、账号、API Key、数据库和临时输出保持本地，不提交仓库。

按用户要求，本机已取消AI次数与金额上限：本地.env中的AI_WEB_MAX_CALLS和AI_WEB_BUDGET_CNY均设为-1。仓库示例仍默认12次/1元；0表示不允许付费调用。调用账本继续累计，失败或结果未知时暂停、价格日期校验及输入输出长度保护仍生效。不限制额度不代表免除模型服务商计费或余额限制。
