# 简化客服 prompt：首轮验证计划

日期：2026-10-10。状态：题目准备完成，真实调用额度待确认，尚未运行。

## 目的与固定条件

验证《客服prompt模板_共创草稿》能否完整、准确、自然地回答当前问题。只验证模型回复，不接网页、不写聊天数据库、不宣称实际转交完成。当前后端没有自动转人工接口接入，回复应提示页面“转人工”入口，而不是声称“已转交”。

固定使用已认可模板的客服说明、全部公开业务资料和默认模拟日期 2026-05-04。模型名称、接口参数和 prompt 文件版本在运行时记录，整轮保持一致。每个独立场景清空历史；多轮场景带入实际上一轮模型回复，不替模型编写正确历史答案。

不使用 T21—T30 保留题。不把下表中的预期、评分或开发说明发送给模型。先完成一轮并保留失败原样，再讨论修改，避免一边测一边改导致结果不可比较。

## 8 类业务场景

以下均为构造开发输入，不是实际用户聊天。日期及商品范围题补充此前已发现的问题，其余沿用或组合已有开发题。

| 编号 | 类别 | 发送给模型的用户消息 | 人工检查要点 |
|---|---|---|---|
| S01 | 商品范围 | 这次团购都卖什么伞，有哪些可以选？ | 只售晴雨双用伞；说明单面内/外花窗、双面内花窗外文字红/黄，均有自动/手动；不新增透明伞或遗漏主要选项 |
| S02 | 款式 | 我要双面花窗在外面的自动款，有吗？ | 解释双面固定内花窗，外花窗为单面且有自动款；不虚构商品，不多问已知条件 |
| S03 | 价格 | 单面、双面分别多少钱？ | 单面45元、双面56元；不增加未知运费、折扣或开合差价 |
| S04 | 模拟日期 | 明天还可以买的吗？ | 按模拟今天2026-05-04推得明天2026-05-05；在历史公告开售期内，截止2026-05-05 23:59；不作现实库存或营业承诺 |
| S05 | 雨天使用 | 防晒伞下雨能用吗？花窗印刷会不会糊？ | 正常雨天可用、公告说明印刷防水；不保证永不掉色或强风暴雨性能 |
| S06 | 检测报告 | 有UPF50+的报告吗？ | 没有可提供的报告，无法确认指标；不推断达标或未达标，不无必要转人工 |
| S07-1 | 使用追问 | 伞怎么收回去？ | 先确认自动/手动；不编详细机械操作 |
| S07-2 | 使用上下文 | 自动款，有教程吗？ | 使用刚提供的型号，不再问；明确视频待补充，不造链接或操作步骤 |
| S07-3 | 主动人工 | 还是不会用，帮我找人工吧。 | 优先人工诉求，说明需人工并提示页面入口；不继续追问、不声称已看过视频或已转交 |
| S08 | 混合诉求 | 单面多少钱？另外我收到就断了，没录开箱，只有刚拍的照片，想换一把。 | 回答45元，同时交人工判断换货、提醒材料；不承诺批准、不因缺视频拒绝、不认定责任，不称照片已提交或审核 |

以上 8 类业务场景共 10 次请求。另用一个独立闲聊场景连续发送“你好”和“谢谢”，共 2 次请求，检查简短自然回应、没有无关商品介绍。整轮计划 12 次，不因错误自动重试或补测。
